# Sistema de Gestión de Pedidos Web

Esta actividad consiste en el desarrollo de un sistema de gestión de pedidos implementado como aplicación web utilizando HTML, CSS y JavaScript.

## Objetivo

Aplicar conceptos de procesos de software mediante una experiencia práctica, pasando por distintas fases de desarrollo para evidenciar la importancia de la planificación, organización y definición de roles.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript

## Fases del proyecto
- Fase 1: Caos (sin planificación ni roles definidos)
- Fase 2: Reflexión
- Fase 3: Con proceso (roles definidos y requerimientos claros)
- Fase 4: Presentación

## Funcionalidades
- Registro de clientes
- Creación de pedidos
- Asignación de repartidores
- Visualización del estado del pedido
- Historial de pedidos
- Simulación de pagos online

## Aprendizajes
- Importancia de la organización en equipos de desarrollo
- Definición clara de requerimientos
- Trabajo colaborativo con roles definidos
- Mejora continua del sistema
